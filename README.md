# ai-classy 🌌

**Sovereign AI Development Layer for Mobile Platforms.**

Built in Termux, **ai-classy** is a high-integrity orchestration layer for Model Context Protocol (MCP) servers, designed with a focus on Privacy-by-Design and SB 24-205 compliance.

## 🛠 Architecture
- **Environment:** Termux (Android/Bionic)
- **Language:** Python 3.11+
- **Orchestration:** Justfile / Makefile
- **Governance:** OPA-driven PII detection & ISO/IEC 42001 alignment.

## 🚀 Quickstart
1. **Clone & Setup:**
   ```bash
   git clone https://github.com/jessburnett/ai-classy.git
   cd ai-classy
   ./reproduce.sh
   ```
2. **Launch Dashboard:**
   ```bash
   python dashboard.py
   ```
